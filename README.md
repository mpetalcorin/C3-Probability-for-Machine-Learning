# Probability & Simulations for Machine Learning 
Practical Jupyter notebooks that explain Monte Carlo simulations, Bayes’ rule, the Central Limit Theorem, and core probability concepts for machine learning—using simple code and real-world examples.

Welcome to a **comprehensive collection of Jupyter notebooks** that explain core probability concepts and simulations for machine learning, **in clear language with real-world examples.**

This project covers everything from **Monte Carlo simulations** to **Bayes’ rule, the Central Limit Theorem, and practical NumPy applications.**

---

## 1. NumPy in Science & Technology

**Notebook:** `C3_numpy_science_tech.ipynb`

Learn how **NumPy turbocharges Python math** and simulate:

- 10,000 coin flips 
- 5,000 rolls of two dice 
- 1,000 customer purchases 
- Basic array math

**Why it matters:** NumPy is the backbone of **AI, data science, and engineering** because it makes working with arrays blazing fast.

## 2. Monte Carlo Simulations – Introductory Examples

**Notebook:** `C3_monte_carlo_simulation_intro.ipynb`

Learn how Monte Carlo simulations **estimate probabilities** by simulating random processes:

- Estimate Pi with random points 
- Toss a coin 1000 times 
- Simulate 10-year investment returns 

**Why it matters:** Monte Carlo simulations solve **hard problems in finance, physics, and AI.**

## 5. Bayes’ Rule, CLT & Salary Data

**Notebook:** `C3_bayes_clt_salary_notebook.ipynb`

Explore deeper probability concepts:

- **Bayes’ rule:** Update beliefs (rain & thunder)
- **Central Limit Theorem (CLT):** Why sample means are normal
- **de Moivre-Laplace theorem:** Binomial vs normal
- **Real-world salary data:** Skewed distributions 
- **Discrete vs continuous variables:** What every ML practitioner should know

**Why it matters:** These concepts are the **foundation of modern statistics and machine learning.**
